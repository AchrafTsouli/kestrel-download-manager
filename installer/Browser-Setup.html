Connect Kestrel to Chrome / Brave

Kestrel is installed. One browser step remains to enable download capture and the video panel.

  1. Open chrome://extensions or brave://extensions in your browser.
  2. Enable Developer mode, then click Load unpacked.
  3. Select this folder:
  1. Pin Kestrel Integration. Open its popup and check the connection. Enable the video panel there if needed.
  2. Refresh existing video tabs. When you update Kestrel, click the extension's reload button and refresh those tabs again.

The native bridge is registered by the installer when the Chrome/Brave option is selected. This extension is distributed locally and is not yet in the Chrome Web Store.

Configuration en français

Ouvrez la page des extensions, activez le Mode développeur, cliquez sur Charger l'extension non empaquetée, puis sélectionnez le dossier ci-dessus. Vérifiez la connexion dans le popup Kestrel et actualisez vos onglets vidéo.
